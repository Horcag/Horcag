# Nikita Lebedev

**Developer tools · Browser research · Document automation**

I build tools for working with coding agents, collecting web sources, and turning
structured content into documents. My projects connect agent interfaces to the
systems that do the work: browsers, local processes, virtual machines, and Word.

[Projects](#selected-projects) · [Open-source contributions](#open-source-contributions) · [Contact](#contact)

## Selected projects

| Project | What it does | Built with |
| --- | --- | --- |
| **[local-web-stack](https://github.com/Horcag/local-web-stack)** | Local web search and browser-assisted research with source provenance, saved evidence, and MCP tools. | Python, SearXNG, Crawl4AI, Docker |
| **[pytest-fsd](https://github.com/Horcag/pytest-fsd)** | Checks Feature-Sliced Design boundaries in Python projects: imports, public APIs, and directory structure. [Available on PyPI](https://pypi.org/project/pytest-fsd/). | Python, pytest, AST |
